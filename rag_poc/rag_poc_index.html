Retrieval-Augmented Generation: Multi-Metric Evaluation for Production Q&A Systems

Home / Projects Single Page

Findings & Recommendations

An end-to-end Retrieval-Augmented Generation system that indexes 48 ML/AI documents (arXiv papers, Wikipedia, technical blogs) using multi-qa-mpnet-base-dot-v1 embeddings and a Qdrant vector store, served by Mistral-Small-24B with persona-routed prompting for technical and marketing audiences. The headline finding: LLM-as-judge has a refusal-penalty bias that inflates scores for verbose answers, so production systems must also track BLEU and semantic similarity. Blind testing landed at 80% plausible and 0% hallucinated.

Implementation & Configuration Sweep

Implementation walkthrough covering chunking strategy, retrieval-pipeline assembly, persona-routed prompting, and a 49-configuration sweep across embedding models, top-k values, and prompt formats. Each configuration is scored on three complementary metrics — BLEU, semantic similarity, and LLM-as-judge — surfacing the divergence patterns that motivate the multi-metric recommendation.
